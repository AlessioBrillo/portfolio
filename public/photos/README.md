# Photos — Optimized Site Images

Optimized, ready-to-serve photos live here. **Raw sources never do** — they stay
in a git-ignored directory on the author's machine (see
[`docs/content/photos.md`](../../docs/content/photos.md) for the full pipeline).

## Convention

```
public/photos/
  {subject}-{width}.avif   AVIF at each delivery width
  {subject}-{width}.webp   WebP at each delivery width
  {subject}-{max}.jpg      JPEG fallback (also the `src` of the asset)
```

- `{subject}` is ASCII, lowercase, hyphenated (`vds-volo-01`, `who-portrait`).
- `{width}` is the rendered pixel width, one of `480`, `960`, `1600`.
- All files are generated by `npm run images`; never hand-edit them — re-run
  the script and re-paste the printed block into the content module.
